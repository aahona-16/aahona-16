### 🧠 Local RAG — Chat With Your Docs, Privately

</div>

A local-first AI app where you can chat with your own PDFs, Word files, and spreadsheets — everything stays on your machine, no cloud needed.

<div align="center">

### 💳 UPI Without Internet — Payments Through a Mesh

</div>

What if you could send money with zero connectivity? This project makes it real — payments are encrypted end-to-end and hop from phone to phone over Bluetooth until one device gets signal and settles the transaction.

The system uses **RSA + AES-GCM encryption** so no middleman can read or tamper the payment, and an **atomic idempotency layer** ensures it settles exactly once — even if three devices upload it simultaneously.

**Built with →** Java · Spring Boot · RSA-OAEP · AES-256-GCM · H2 DB

[![View Project](https://img.shields.io/badge/→%20View%20on%20GitHub-0d1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/aahona-16/UPI_Without_Internet)
