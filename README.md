## Signature Projects

### Local RAG - Chat With Your Documents Privately

Local-first AI assistant to chat with PDFs, DOCX, spreadsheets, and images while keeping data on your machine.

- AI vision extracts charts and tables from documents.
- Memory vault stores user preferences across sessions.
- Multimodal chat supports screenshot and mixed input.

Tech: Python, Flask, Elasticsearch, Gemini Flash, SQLite

[![View Project](https://img.shields.io/badge/View%20on%20GitHub-0d1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/aahona-16/Local-RAG)

### AI Clinic Receptionist - Healthcare Workflow Automation

Intelligent receptionist for clinics that answers patient queries and automates appointment scheduling.

- 24/7 assistant flow for patient interactions.
- Smart intent handling with real-time responses.
- Reduced manual scheduling workload by 60 to 80 percent.

Tech: React, Node.js, Express, OpenAI GPT, Firebase

[![View Project](https://img.shields.io/badge/View%20on%20GitHub-0d1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/aahona-16/ai-clinic-receptionist)

### Deep Packet Analyzer - Real-Time Network Security

High-performance network traffic analyzer built in C++ for classification and rule-based blocking.

- Parses PCAP traffic with multi-threaded processing.
- Identifies applications using TLS SNI and HTTP headers.
- Generates clean outputs for security workflows.

Tech: C++, PCAP, Multi-threading, TLS SNI

[![View Project](https://img.shields.io/badge/View%20on%20GitHub-0d1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/aahona-16/Packet_analyzer)

### UPI Without Internet - Offline Mesh Payments

Secure peer-to-peer payment forwarding over Bluetooth mesh with deferred settlement once connectivity is available.

- End-to-end cryptography with RSA and AES-GCM.
- Atomic idempotency layer guarantees exactly-once settlement.
- Designed for low-connectivity real-world use.

Tech: Java, Spring Boot, RSA-OAEP, AES-256-GCM, H2

[![View Project](https://img.shields.io/badge/View%20on%20GitHub-0d1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/aahona-16/UPI_Without_Internet)
